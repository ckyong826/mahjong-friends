# Rules decisions pending review

## Tile inventory

The common standard core is 136 tiles (108 suit, 16 winds, 12 dragons).
Optional modules: 8 unique flower/season tiles, 4 unique animal tiles, and 0–4 blank Fei jokers.

A "Fei" tile has an intentionally blank face, and is not the white dragon. It stays concealed as a playable wildcard and is **not** automatically replaced like a flower or animal.

## Replacement semantics

Shuffle first, then reserve a configurable replacement wall.
A revealed bonus from the live wall must be replaced from the replacement wall; consecutive bonuses need more replacements. A kong draws from the same reserved source.
If the replacement wall runs out, the drawing function returns exhausted=true with all revealed bonuses accounted for. Turn flow decides whether this ends a round.
